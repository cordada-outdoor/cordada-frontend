# Cordada Outdoor

This is the frontend code to the Cordada Outdoor website.

## Available Scripts

- `npm start` — Vite dev server on [http://localhost:3000](http://localhost:3000).
- `npm test` — Vitest in watch mode.
- `npm run build` — typecheck and build for production into `build/`.
- `npm run preview` — serve the production build locally.
